# API 文档

## 1. 约定

- Base URL：`https://<域名>/api/v1`
- 健康检查：`/actuator/health` 仅供部署环境内部探活，反向代理不对外暴露
- 请求/响应：`application/json; charset=UTF-8`
- 上传：`multipart/form-data`
- 认证：除注册、登录外，所有接口需 `Authorization: Bearer <JWT>`
- 时间：ISO-8601 UTC，例如 `2026-10-28T07:41:55Z`；客户端按设备时区展示
- 字段命名：JSON camelCase，数据库 snake_case
- 所有普通接口统一 envelope：

```json
{
  "success": true,
  "data": {},
  "message": null,
  "code": null,
  "timestamp": "2026-10-28T07:41:55Z"
}
```

失败：

```json
{
  "success": false,
  "data": null,
  "message": "你已完成本次签到，无需重复提交",
  "code": "ALREADY_CHECKED_IN",
  "timestamp": "2026-10-28T07:41:55Z"
}
```

图片接口是二进制流，不使用 envelope。

## 2. 认证与角色

| 项 | 说明 |
| --- | --- |
| JWT 载荷 | subject=用户 ID，包含 username/name/role |
| 默认有效期 | 168 小时，可由 `JWT_EXPIRATION_HOURS` 配置 |
| 密码存储 | BCrypt strength 12 |
| 角色 | `STUDENT`、`TEACHER`，由服务端账号记录决定 |
| 教师账号 | 一次性 `BOOTSTRAP_TEACHER_*` 环境变量创建首个教师；不开放注册接口 |
| 学生注册 | 固定创建 STUDENT，学号唯一 |

Android 将 token 保存在 DataStore；401/TOKEN_INVALID 时清除本机会话并回到登录页。

### 3.8 管理员接口

管理员接口前缀为 `/api/admin`，只接受独立的管理员会话 Cookie，不接受教师或学生 JWT。所有非 GET 请求还必须携带登录时返回的 `X-CSRF-Token`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/admin/auth/login` | 管理员登录，设置 HttpOnly 会话 Cookie |
| GET | `/api/admin/auth/session` | 读取当前管理员会话和 CSRF token |
| POST | `/api/admin/auth/logout` | 删除服务端会话并清除 Cookie |
| GET | `/api/admin/summary` | 教师、学生、课程、归档和软删除数量 |
| GET/POST | `/api/admin/accounts` | 搜索/创建教师或学生账号 |
| PUT | `/api/admin/accounts/{id}` | 编辑姓名，带版本校验 |
| POST | `/api/admin/accounts/{id}/reset-password` | 重置密码并使旧 JWT 失效 |
| DELETE | `/api/admin/accounts/{id}` | 删除账号；教师课程或学生个人记录级联清理 |
| GET | `/api/admin/accounts/{id}/student-detail` | 学生各课程只读成绩汇总 |
| GET/POST | `/api/admin/courses` | 搜索、状态筛选、创建课程 |
| PUT | `/api/admin/courses/{id}` | 编辑课程和任课教师，带版本校验 |
| POST | `/api/admin/courses/{id}/archive` | 归档 |
| POST | `/api/admin/courses/{id}/unarchive` | 取消归档 |
| POST | `/api/admin/courses/{id}/invite-code/reset` | 重置邀请码 |
| DELETE | `/api/admin/courses/{id}` | 软删除 |
| GET | `/api/admin/courses/{id}/impact` | 永久删除影响预览 |
| DELETE | `/api/admin/courses/{id}/permanent` | 永久删除并清理上传图片 |
| GET/POST | `/api/admin/courses/{id}/members` | 查看或添加成员 |
| DELETE | `/api/admin/courses/{id}/members/{studentId}` | 移除成员，保留历史记录 |
| GET | `/api/admin/courses/{id}/detail` | 课程、成员、题目和作业只读详情 |

管理员登录按来源 IP 与账号做 10 分钟滑动限速，连续 5 次失败后拒绝登录。管理页面 `/admin` 每 5 秒刷新可见数据，编辑表单与确认框不参与自动刷新。

## 4. 请求/响应示例

### 4.1 学生注册

```http
POST /api/v1/auth/register
Content-Type: application/json
```

```json
{
  "studentNo": "S1001",
  "name": "Student A",
  "password": "Student@123"
}
```

`201 Created`：

```json
{
  "success": true,
  "data": {
    "token": "<jwt>",
    "user": {
      "id": 2,
      "username": "S1001",
      "name": "Student A",
      "role": "STUDENT"
    }
  },
  "message": null,
  "code": null,
  "timestamp": "2026-10-28T07:41:55Z"
}
```

学号 4–40 位字母/数字/下划线/短横线；密码 8–64 位；姓名 2–30 字。

```http
POST /api/v1/auth/login
```


### 4.8 发布问题

```http
POST /api/v1/courses/1/questions
Authorization: Bearer <teacher-jwt>
```

单选：

```json
{
  "type": "SINGLE_CHOICE",
  "prompt": "下列哪种结构遵循 LIFO？",
  "options": ["队列", "链表", "栈", "堆"],
  "correctAnswer": "C",
  "deadlineAt": "2026-10-28T08:30:00Z"
}
```

多选：

```json
{
  "type": "MULTIPLE_CHOICE",
  "prompt": "下列哪些是关系型数据库？",
  "options": ["MySQL", "Redis", "PostgreSQL", "MongoDB"],
  "correctAnswer": "A,C",
  "deadlineAt": "2026-10-28T08:30:00Z"
}
```

填空：

```json
{
  "type": "FILL_BLANK",
  "prompt": "快速排序平均时间复杂度？",
  "correctAnswer": "O(n log n)",
  "deadlineAt": "2026-10-28T08:30:00Z"
}
```

选择题选项 2–6 个；单选题 `correctAnswer` 为一个合法选项键，多选题用逗号分隔至少两个合法键（如 `A,C`），服务端会按选项顺序规范化。截止时间必须晚于当前时间。

### 4.9 作答

```http
POST /api/v1/questions/1/answers
Authorization: Bearer <student-jwt>
```

```json
{"answer":"O(N LOG N)"}
```

```json
{
  "success": true,
  "data": {
    "questionId": 1,
    "answer": "O(N LOG N)",
    "isCorrect": true,
    "correctAnswer": "O(n log n)",
    "submittedAt": "2026-10-28T08:12:30Z"
  }
}
```

每题一次；截止后 `422 QUESTION_CLOSED`；无权限 `403 NOT_MEMBER`；重复提交 `409 ALREADY_ANSWERED`。

### 4.10 上传/替换作业

```http
POST /api/v1/assignments/1/submissions
Authorization: Bearer <student-jwt>
Content-Type: multipart/form-data
```

字段：

- `file`：JPEG/PNG，≤10 MB
- `note`：可选，≤500 字

```bash
curl -X POST "https://class.example.com/api/v1/assignments/1/submissions" \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@homework.jpg;type=image/jpeg" \
  -F "note=第一版"
```

成功返回 `SubmissionDto`，其中 `imageUrl` 为 `/api/v1/submissions/{id}/image`，`version` 为提交的乐观锁版本。同一作业重复上传会更新原记录、递增 `version`、清空旧评分并返回相同 `id`。教师评分时必须回传看到的 `version`，版本不一致返回 `SUBMISSION_CHANGED`。

错误：`FILE_TOO_LARGE`（413）、`UNSUPPORTED_FILE_TYPE`（415）、`ASSIGNMENT_CLOSED`（422）、`NOT_MEMBER`（403）。

## 6. 图片访问与 Nginx

1. 图片保存在 `UPLOAD_DIR/assignments/{assignmentId}/{uuid}.jpg|png`。
2. Nginx 的 `/uploads/` location 固定返回 404，不映射静态目录。
3. Android 通过 `GET /api/v1/submissions/{id}/image` 携带 Bearer token 获取：
   - 学生仅当 `submission.student_id == current_user.id`；
   - 教师仅当 `course.teacher_id == current_user.id`；
   - 其他情况 403。
4. 响应头：`Content-Type`=保存时的 MIME，`Content-Disposition: inline`，`Cache-Control: no-store`，`X-Content-Type-Options: nosniff`。
5. 服务端拒绝 `..` 路径、非普通文件、非 JPEG/PNG magic 的上传。

## 7. 速率与大小限制

- Nginx：`/api/` 30 r/s/IP，burst 60；请求体最大 11 MB。
- Spring multipart：单文件 10 MB，请求 12 MB。
- 应用层：再次检查文件 ≤10 MB、note ≤500 字、标题/题干长度等。

## 8. 兼容性

接口前缀固定 `/api/v1`。新增字段遵循向后兼容；不改变已有字段含义。Android 端使用 Retrofit + Gson，未配置字段会置空/默认值。
